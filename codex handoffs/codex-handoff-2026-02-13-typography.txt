Typography Consistency Requirement
==================================

Priority: HIGH

User Request:
-------------
Ensure typography is consistent throughout the entire website. 
Do NOT use more than 3 fonts maximum.

Approved Font Stack (3 fonts only):
-----------------------------------
1. Bebas Neue (Display/Headings)
   - CSS variable: --font-display
   - Usage: Headers, titles, display text, brand name
   - Characteristics: Bold, condensed, industrial aesthetic
   - Tailwind class: font-display

2. Inter (Sans-serif/Body)
   - CSS variable: --font-sans
   - Usage: Body text, UI elements, descriptions, general content
   - Characteristics: Modern, highly readable, versatile
   - Tailwind class: font-sans

3. JetBrains Mono (Monospace/Data)
   - CSS variable: --font-mono
   - Usage: Data labels, technical text, code, metrics, numbers
   - Characteristics: Clear, technical, excellent for numbers
   - Tailwind class: font-mono
