QUICK START
===========
1. npm install
2. Setup Supabase (run migrations)
3. Create .env.local (use template)
4. npm run dev
5. Open http://localhost:3000

DEPLOYMENT
==========
1. Push to GitHub
2. Connect to Vercel
3. Configure environment variables
4. Deploy automatically

For details: See DEPLOYMENT.md
